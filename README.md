# BBFRAXY

Osobní web FraXyho — místo pro hry, nástroje, projekty, experimenty a další věci.

🌐 **Web:** https://bbfraxy.com/

## Co tu najdeš

### 🎮 Games
Hry a interaktivní experimenty. Najdeš tu kvízy, vědomostní hry, tipovací soutěže a multiplayerové hry pro hraní s přáteli.

### 🛠 Tools
Malé nástroje a utility, které mají něco zjednodušit, urychlit nebo zpříjemnit.

### 🧩 Projects
Větší osobní projekty, experimenty a věci, které se nevejdou jen do jedné hry nebo nástroje.

### 📦 Downloads
Místo pro projekty a další věci, které jsou připravené ke stažení nebo se na jejich vydání pracuje.

### 🔐 Privacy
Stránka `/privacy/` s informacemi o soukromí, lokálním úložišti, cookies a používaných externích službách.

## Vzhled a fungování

BBFRAXY používá vlastní jednotný vizuální styl, společnou navigaci, responzivní rozložení a podporu dark/light režimu.

Jednotlivé hry a nástroje fungují přímo v prohlížeči. Větší části projektu mají vlastní oddělené soubory a moduly, aby zůstaly přehledné a snadno se dál rozšiřovaly.

## Technologie

Základem je HTML, CSS a JavaScript. Podle konkrétní stránky se používají také další knihovny a služby, například Leaflet a OpenStreetMap pro mapové hry nebo html2canvas pro export výsledků.

## Stav projektu

BBFRAXY je průběžně vyvíjený osobní projekt. Některé části jsou hotové a použitelné, jiné jsou stále ve vývoji nebo slouží jako základ pro další nápady.
