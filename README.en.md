# BBFRAXY

FraXy's personal web hub — a place for games, tools, projects, experiments and other things.

🌐 **Website:** https://bbfraxy.com/

## What you'll find here

### 🎮 Games
Games and interactive experiments, including quizzes, knowledge games, guessing challenges and multiplayer games to play with friends.

### 🛠 Tools
Small utilities and experiments designed to make things simpler, faster or more useful.

### 🧩 Projects
Larger personal projects, experiments and ideas that go beyond a single game or tool.

### 📦 Downloads
A place for projects and other files that are ready to download or are being prepared for release.

### 🔐 Privacy
A `/privacy/` page with information about privacy, local storage, cookies and external services used by the site.

## Design & experience

BBFRAXY uses a shared visual system, common navigation, responsive layouts and dark/light theme switching.

Games and tools run directly in the browser. Larger parts of the project use separate files and modules to keep them readable and easy to expand.

## Technology

The site is primarily built with HTML, CSS and JavaScript. Some pages also use additional libraries and services, such as Leaflet and OpenStreetMap for map-based games or html2canvas for result exports.

## Project status

BBFRAXY is an evolving personal project. Some sections are finished and ready to use, while others are still being developed or used as a foundation for future ideas.
